### Key Discussion Points Covered in the Deck:
1. **The Friction of Conventional E-Commerce**: UI fatigue, manual dark store routing, and basket configuration hurdles.
2. **Model Context Protocol (MCP)**: Standardized JSON-RPC protocol bridging LLMs with external live services.
3. **System Architecture**: Claude Desktop $\leftrightarrow$ `mcp-remote` $\leftrightarrow$ Zepto Remote MCP Server $\leftrightarrow$ Core Microservices.
4. **Verified Tool Suite**: 8 production tools spanning order history, product lookup, cart mutations, and checkout.
5. **Autonomous Error Recovery**: Self-healing mechanism resolving `"Store not selected"` by binding saved user addresses.
6. **Two-Phase Safety Commit**: Enforcing preview stages (`confirm: false`) before executing financial transactions (`confirm: true`).
7. **Empirical Results & Live Order**: Verified live order completion with complete delivery fee transparency.
